\appx{E}{Terminal Evidence Figures (Real Output)}
The figures below are rendered from the evidence files by \code{scripts/render-evidence-figures.py} (headless Chrome, dark terminal style). The text is cut from the files unchanged, except that very long lines are wrapped, a few verbose driver messages are shortened where the caption says \emph{condensed}, and md5 digests are truncated. No key, hash, password or token appears in any of them. Each caption says what the output demonstrates; the figures used in the body (privileges, SQL injection before the fix) are in Sections~\ref{sec:rbac} and~\ref{sec:sqli}.
